# Hotel setup worksheet

Template for the future pilot hotel. Fill with authorised business information; never put live secrets in this file.

| Field | Value / decision |
|---|---|
| Hotel trading name and receipt identity | To be supplied |
| Installation ID / release | Generated during setup |
| Operating contact / incident owner | To be assigned |
| Currency / timezone | KES / Africa/Nairobi |
| Business-day cutoff | Hotel decision |
| Table labels and typical guests | Hotel inventory |
| Tablet/kiosk/display models and OS | Hardware pilot results |
| Kitchen/bar stations and routing | Hotel workflow |
| Receipt/kitchen printer model and transport | Tested compatibility |
| M-PESA provider and merchant status | O01 evidence; no credentials here |
| External card terminal and cashier process | Provider/terminal reference rules |
| Cash custody and handover schedule | O06 decision |
| Shared items / individual checkout | O05 decision |
| Kiosk eat-in collection | O08 decision |
| Taxes, invoice rules and integrator | O02 accountant/integrator approval |
| Menu/photo/recipe owner | Kitchen/content leads |
| Languages and translation reviewer | O07 decision |
| Backup destination and restore targets | O10 operational approval |
| Retention/privacy contact | Hotel-approved policy |
| Staff training dates and sign-off | Pilot record |

Attach tested network diagram, photo inventory, menu approval, fiscal configuration evidence, provider test references, staff role assignments, and acceptance results. Secret values belong in protected installation configuration, not ordinary documentation or email.
